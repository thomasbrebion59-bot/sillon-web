# Sillon (version web)

Sillon est un « second cerveau » : tes cours, tes idées et tes fiches de révision, rangés dans un cerveau 3D que tu peux personnaliser (30 univers, couleur du cerveau entier, 24 thèmes).

Cette page est **l'app construite** (aucun code source). Ouvre-la sur ton téléphone, puis « Ajouter à l'écran d'accueil ».

- Tes données restent **sur ton appareil** (stockage du navigateur) ; rien n'est envoyé.
- Le cortex 3D vient du modèle Colin27 (licence McGill jointe : `assets/COLIN27-LICENSE.txt`).
